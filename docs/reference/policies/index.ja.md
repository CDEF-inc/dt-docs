# ポリシー

Dependency-Track には 2 種類のポリシーがあります。どちらも [CEL](../cel-expressions.md) で記述した条件をコンポーネントとプロジェクトに対してチェックしますが、作用する対象と出力が異なります。

* **[コンポーネントポリシー](component-policies.md)**は、条件に一致したコンポーネントに対して*違反*を発生させます。許容するライセンス、使用禁止のコンポーネント、経過期間の上限など、組織の基準をルール化するために使います。
* **[脆弱性ポリシー](vulnerability-policies.md)**は、個々の脆弱性の検出結果にトリアージの*分析*を適用します。ポートフォリオ全体で抑制やレーティングの上書きを一元管理するために使います。

2 種類のポリシーは、CEL の評価コンテキストとカスタム関数ライブラリを共有しています。両方に適用される変数、カスタム関数、実例については、[条件式](condition-expressions.md)を参照してください。

背景情報については、[コンポーネントポリシーについて](../../concepts/component-policies.md)と[脆弱性ポリシーについて](../../concepts/vulnerability-policies.md)を参照してください。
