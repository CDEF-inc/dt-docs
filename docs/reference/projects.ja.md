# プロジェクト

プロジェクトのフォーム、プロジェクトの詳細ページ、プロジェクト関連の管理パネルの UI リファレンスです。背景については[プロジェクトについて](../concepts/projects.md)を、手順についてはユーザーガイドを参照してください。

- [プロジェクトを階層に整理する](../guides/user/organizing-projects.md)
- [プロジェクトのバージョンを管理する](../guides/user/managing-project-versions.md)
- [プロジェクトの保持期間を設定する](../guides/administration/configuring-project-retention.md)

リクエストとレスポンスのスキーマについては、[v1](api/v1.md) と [v2](api/v2.md) の OpenAPI 仕様を参照してください。

## 分類子 {#classifiers}

プロジェクトの分類子は、CycloneDX の `metadata.component.type` 列挙型に対応しています。値は、プロジェクトのフォームの *Classifier* ドロップダウンにそのまま表示されます。

| 分類子                   | 説明                              |
|:-------------------------|:----------------------------------|
| `APPLICATION`            | ソフトウェアアプリケーション。    |
| `FRAMEWORK`              | ソフトウェアフレームワーク。      |
| `LIBRARY`                | ソフトウェアライブラリ。          |
| `CONTAINER`              | コンテナーイメージ。              |
| `PLATFORM`               | コンピューティングプラットフォーム。 |
| `OPERATING_SYSTEM`       | オペレーティングシステム。        |
| `DEVICE`                 | 物理デバイス。                    |
| `DEVICE_DRIVER`          | 物理デバイスのドライバー。        |
| `FIRMWARE`               | デバイスのファームウェア。        |
| `FILE`                   | 単独のファイル。                  |
| `MACHINE_LEARNING_MODEL` | 機械学習モデル。                  |
| `DATA`                   | データセット。                    |

コレクションプロジェクトには分類子がありません。プロジェクトをコレクションモードに切り替えると、*Classifier* フィールドは非表示になります。

## コレクションロジック {#collection-logic}

*Project Collection Logic* ドロップダウンは、コレクションプロジェクトでの集計方法を設定します。設定されている間、プロジェクトは独自のコンポーネント、サービス、依存関係グラフを持つことができず、BOM のアップロードも受け付けません。

| 値                                   | 集計                                                                                                     |
|:-------------------------------------|:---------------------------------------------------------------------------------------------------------|
| `AGGREGATE_DIRECT_CHILDREN`          | すべての直接の子が親のメトリクスに集計されます。                                                         |
| `AGGREGATE_DIRECT_CHILDREN_WITH_TAG` | 設定された *Collection Tag* を持つ直接の子だけが集計されます。*Collection Tag* は必須です。              |
| `AGGREGATE_LATEST_VERSION_CHILDREN`  | 最新バージョンとしてマークされた直接の子だけが集計されます。                                             |

## 識別情報 {#identity}

| フィールド | 必須   | 制限                                                                        |
|:--------|:--------:|:----------------------------------------------------------------------------|
| 名前    | はい     | 最大 255 文字。                                                             |
| バージョン | いいえ | 最大 255 文字。不透明なテキストとして扱われ、解析や並べ替えは行われません。 |

名前とバージョンの組み合わせは、プロジェクトが階層のどこにあるかに関係なく、インスタンス全体で一意です。

## 識別子 {#identifiers}

プロジェクトのフォームでは、脆弱性の照合に使うエコシステムの識別子を指定できます。

| フィールド  | 制限       | 用途                                                               |
|:------------|-----------:|:-------------------------------------------------------------------|
| PURL        | 1024 文字  | Package URL。脆弱性の照合に使う主要な識別子。                      |
| CPE         |  255 文字  | CPE 2.2 または 2.3 の識別子。NVD 方式の照合に使います。            |
| SWID Tag ID |  255 文字  | SWID タグの識別子。実際にはほとんど使われません。                   |

## タグとプロパティ {#tags-and-properties}

プロジェクトには、タグとプロジェクトプロパティをいくつでも付けられます。

| エンティティ     | 制限                                                                                                              | 備考                                                                   |
|:-----------------|:------------------------------------------------------------------------------------------------------------------|:-----------------------------------------------------------------------|
| タグ             | 名前は印字可能文字で最大 255 文字。インスタンス全体で一意。                                                      | プロジェクトとは多対多の関係。[タグについて](../concepts/tags.md)を参照してください。 |
| プロジェクトプロパティ | グループと名前は 1 から 255 文字で、制御文字は使えません。値は最大 1024 文字。型は必須です。              | プロジェクト単位のキーと値のメタデータで、そのプロジェクトをスコープとします。 |

## 保持の設定 {#retention-configuration}

*Administration > Configuration > Maintenance > Projects Retention* で設定します。設定手順については、[プロジェクトの保持期間を設定する](../guides/administration/configuring-project-retention.md)を参照してください。

| コントロール                         | デフォルト   | 用途                                                                                                                   |
|:-------------------------------------|:-------------|:-----------------------------------------------------------------------------------------------------------------------|
| *Enable Inactive Project Deletion*   | オフ         | マスタースイッチ。オフの間、メンテナンスタスクは何もしません。                                                         |
| *Project Retention Type*             | 未設定       | *AGE* は廃止されてからの経過期間で削除します。*VERSIONS* はプロジェクト名ごとに最新の非アクティブなバージョンを保持します。 |
| *AGE* スライダー                     | 30 日        | *AGE* モードのしきい値。次回のタスク実行で、これより古い非アクティブなプロジェクトが削除されます。                     |
| *VERSIONS* スライダー                | 2 バージョン | *VERSIONS* モードで、プロジェクト名ごとに保持する最新の非アクティブなバージョンの数。タスクはそれより古いバージョンを削除します。 |
