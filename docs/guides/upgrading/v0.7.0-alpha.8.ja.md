# v0.7.0-alpha.8 へのアップグレード

* **`PROJECT_VULN_ANALYSIS_COMPLETE` 通知を削除しました**。この通知はモデルが最適ではなく、内容の生成にもコストがかかっていました。UI から設定できたことは一度もなかったため、このリリースで削除します。ユーザーの要望に応じて、将来のリリースで同様の機能が再導入される可能性があります。
* **Java のベースラインを 25 に引き上げました**。アプリケーションのビルドと実行には Java 25 が必要になりました。公式のコンテナーイメージは、2025 年 9 月から Java 25 を同梱しています。この変更は、アプリケーションをソースからビルドするユーザーや、カスタムのコンテナーイメージを組み立てるユーザーにだけ影響します。
