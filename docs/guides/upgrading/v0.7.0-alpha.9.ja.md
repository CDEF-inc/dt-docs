# v0.7.0-alpha.9 へのアップグレード

* **`/api/v1/component/*` エンドポイントから `componentMetaInformation` フィールドを削除しました**。このデータ(公開日時のタイムスタンプ、リポジトリから取得したハッシュ)は、`/api/v2/components` の `package_metadata` と `package_artifact_metadata` で取得できるようになりました。詳しくは、[API v2 の OpenAPI 仕様][openapi-v2]を参照してください。
* **API v2 に `expand` で展開できるフィールドを導入しました**。一部のフィールドはデフォルトでレスポンスから除外されるようになりましたが、`expand` クエリーパラメーターを使って展開できます。これは `/api/v2/components` と `/api/v2/projects/{uuid}/components` のエンドポイントに影響し、今後は `metrics` と `occurrence_count` を明示的に展開する必要があります。詳しくは、[API v2 の OpenAPI 仕様][openapi-v2]を参照してください。
* **LDAP の同期ジョブを削除しました**。LDAP 連携は、ユーザーとチームのメンバーシップを非同期で同期しなくなりました。代わりに、ユーザーがログインに成功したときにその都度同期します。これは OIDC 連携の動作と同じです。
* **スケジュール済みタスクの設定項目を簡素化しました**。次の設定プロパティは使われなくなりました。
    * `(alpine|dt).worker.threads`
    * `(alpine|dt).worker.thread.multiplier`
    * `(alpine|dt).worker.pool.drain.timeout.duration`
    * `dt.task.internal.component.identification.lock.max.duration`
    * `dt.task.internal.component.identification.lock.min.duration`
    * `dt.task.vulnerability.analysis.lock.max.duration`
    * `dt.task.vulnerability.analysis.lock.min.duration`
    * `dt.task.epss.mirror.lock.max.duration`
    * `dt.task.epss.mirror.lock.min.duration`
    * `dt.task.internal.component.identification.cron`
    * `dt.task.metrics.maintenance.lock.max.duration`
    * `dt.task.metrics.maintenance.lock.min.duration`
* **却下された脆弱性と取り下げられた脆弱性をサポートしました**。内部アナライザーは、ソースによって却下または取り下げられた脆弱性を報告しなくなりました。UI では、そのような脆弱性に *Rejected* バッジが表示されるようになりました。
