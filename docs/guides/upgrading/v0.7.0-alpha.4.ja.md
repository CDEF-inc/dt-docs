# v0.7.0-alpha.4 へのアップグレード

* **以前のワークフロー REST API エンドポイントを削除しました**。`/api/v1/workflow` 以下のすべてのパスは利用できなくなりました。BOM のアップロードの処理など、特定のタスクがまだ進行中かどうかを確認するには、`/api/v1/bom/token/{uuid}` または `/api/v1/event/token/{uuid}` を使ってください。
* **アドバイザリーと CSAF の REST API エンドポイントを削除しました**。`/api/v2/advisories` と `/api/v2/csaf` 以下のすべてのパスは利用できなくなりました。この機能の実装を GA リリースまでに完成できなかったため、機能を削除しました。
* **Protobuf 形式の CycloneDX BOM のインポートのサポートを削除しました**。受け付ける形式は JSON と XML だけになります。
* **ファイルからのシークレットの読み込みに `${file::}` 式の構文を使うようになりました**。以前の `<key>.file=/path` と `alpine.<key>.file=/path` プロパティは認識されなくなり、これらのいずれかが設定されている場合、API サーバーは起動を拒否します。それぞれを `<key>=${file::/path}` に書き換えてください。影響を受けるプロパティは次のとおりです。

    | 変更前                                                                 | 変更後                                  |
    |:-----------------------------------------------------------------------|:----------------------------------------|
    | `dt.database.password.file`(または `alpine.database.password.file`)     | `dt.datasource.password=${file::/path}` |
    | `dt.http.proxy.password.file`(または `alpine.http.proxy.password.file`) | `dt.http.proxy.password=${file::/path}` |
    | `dt.ldap.bind.password.file`(または `alpine.ldap.bind.password.file`)   | `dt.ldap.bind.password=${file::/path}`  |

    ファイルは起動時に 1 回だけ読み込まれ、UTF-8 としてデコードされ、末尾の空白が取り除かれます。64 KiB より大きいファイルは拒否されます。詳しくは、[ファイルから値を読み込む](../../reference/configuration/application.md#loading-values-from-files)を参照してください。
