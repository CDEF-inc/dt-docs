# v5.0.0-rc.2 へのアップグレード

!!! danger "従来の `alpine.*` とプレフィックスのないプロパティ名は受け付けられなくなりました"
    このリリースでは、v4 時代の `alpine.*` やプレフィックスのないプロパティ名(たとえば `alpine.ldap.enabled`、`database.url`、`bcrypt.rounds`)を対応する `dt.*` の名前に変換していた互換性のための仕組みを廃止しました。これらの名前を使っている設定は、現在の `dt.*` プロパティに移行してください。誤った設定が気付かれないまま使われるのを防ぐため、**API サーバーは従来のキーを検出すると起動を拒否します**。

    `alpine.*` から `dt.*` への当初の移行については、[v0.7.0-alpha.3 のアップグレードノート](v0.7.0-alpha.3.md)で説明しています。サポートされるプロパティと、対応する環境変数の表記の正式な一覧については、[Configuration Properties](../../reference/configuration/properties.md) を参照してください。

    RC ビルドで破壊的変更を加えてしまったことをお詫びします。

!!! warning
    このリリースでは、GA リリースに先立って命名の一貫性を保つため、約 100 個の設定プロパティの名前を変更しています。エイリアスや後方互換性のための仕組みはありません。アップグレードする前に、影響を受ける設定を更新してください。

* **設定プロパティの名前が変更されました**。変更後の名前では、一貫してケバブケースのセグメントを使い、関連するプロパティを共通の名前空間にまとめています。旧名から新名への対応の全一覧を、セクションごとに以下に示します。
