# アップグレードガイド

各リリースの破壊的変更とその他の注目すべき変更、および必要な手動の手順です。

!!! warning "マイナーバージョンは 1 つずつアップグレードする"
    現在のバージョンからアップグレード先のバージョンまでの間にあるすべてのマイナーバージョンについて、リリース順にガイドを確認してください。たとえば `5.0.x` から `5.1.x`、さらに `5.2.x` の順です。マイナーバージョン内のパッチリリースは飛ばしてかまいません。たとえば `5.0.1` から `5.0.5` にする場合は、間にあるすべてのパッチリリースのガイドを読んだうえで、1 回でアップグレードします。

## 関連するガイド {#related-guides}

- [稼働中のインスタンスをアップグレードする](../administration/upgrading-instances.md): 計画的なダウンタイムなしで、稼働中のクラスターをローリングアップグレードします。
- [v4 から v5 に移行する](../administration/migrating-from-v4.md): v4(PostgreSQL または Microsoft SQL Server)から v5(PostgreSQL のみ)への 1 回限りのデータ移行です。
