# v5.1.1 へのアップグレード

* **アップグレードにより、GitHub Advisories と OSV の完全なミラーリングが強制されます**。Dependency-Track は CVSSv4 スコアを基本評価基準だけから算出していたため、現状評価基準も持つアドバイザリーについて、データソースよりも高い深刻度を報告していました。アップグレードでは、両方のデータソースが差分の進捗を追跡するために使うウォーターマークを削除します。既存のデータはそのまま残りますが、各データソースの次回の実行ではデータセット全体を処理し、影響を受けるレコードを上書きします。このリリースではミラーリングが大幅に高速化されているため、完全な実行にかかる時間は以前のバージョンよりも短くなります。

    修正されたデータは、ミラーリングが実行されるまで利用できません。デフォルトでは、GitHub Advisories は毎日 02:00 UTC、OSV は毎日 03:00 UTC に実行されます。修正されたデータをより早く取得するには、[初回のミラーリングをトリガーする](../administration/configuring-vulnerability-sources.md#triggering-an-initial-mirror)の説明に従って **Mirror now** を使ってください。
