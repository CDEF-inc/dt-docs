# v5.0.5 へのアップグレード

* **カスタムの通知テンプレートの更新が必要です**。メール、Mattermost、Microsoft Teams、Slack の各パブリッシャーのデフォルトテンプレートが v5 の通知モデルに存在しない変数を参照していたため、`POLICY_VIOLATION` と `PROJECT_AUDIT_CHANGE` の通知で値が空のまま表示されたり、通知の送信に失敗したりしていました。Dependency-Track は起動時に自身のデフォルトテンプレートを置き換えますが、クローンまたはカスタマイズしたテンプレートには壊れた参照が残ります。影響を受けるテンプレートに、次の名前の変更を適用してください。

    | 変更前 | 変更後 |
    | --- | --- |
    | `subject.policyViolation.policyCondition` | `subject.policyViolation.condition` |
    | `subject.violationAnalysis` | `subject.analysis` |

* **アップグレードにより、OSV の完全なミラーリングが強制されます**。Dependency-Track は一部の OSV のバージョン範囲を誤って変換していたため、コンポーネントを、そのコンポーネントに影響しない脆弱性と照合していました。アップグレードでは、OSV 脆弱性データソースが差分の進捗を追跡するために使うウォーターマークを削除します。既存の OSV のデータはそのまま残りますが、次回のミラーリングの実行では、最近の変更だけでなく OSV のデータセット全体を処理し、影響を受けるレコードを上書きします。この実行には通常より時間がかかることを想定してください。

    修正されたデータは、OSV のミラーリングが実行されるまで利用できません。デフォルトでは、OSV のミラーリングは毎日 03:00 UTC に実行されます。修正されたデータをより早く取得するには、[初回のミラーリングをトリガーする](../administration/configuring-vulnerability-sources.md#triggering-an-initial-mirror)の説明に従って **Mirror now** を使ってください。
