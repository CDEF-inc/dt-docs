# v5.0.0-rc.1 へのアップグレード

!!! tip
    バージョン `5.0.0-rc.1` は、実質的に [`0.7.0-alpha.9`](v0.7.0-alpha.9.md) と同じです。以下で説明するコンテナーイメージの名前とタグの更新を除き、手動のアップグレード手順やデータベースのマイグレーションは必要ありません。

* **バージョン番号の変更**。Hyades プロジェクトは、Dependency-Track の本流に戻ります。バージョン番号は、これが Dependency-Track の次のメジャーバージョンであることを正確に反映するようになりました。これまでの「Hyades `0.7.0-alpha.9`」、「Hyades API サーバー `5.7.0-alpha.9`」、「Hyades フロントエンド `5.7.0-alpha.9`」は、それぞれ「API サーバー `5.0.0-rc.1`」と「フロントエンド `5.0.0-rc.1`」になりました。
* **コンテナーイメージの移動**。コンテナーイメージの名前も、本流に戻ったことを反映しています。

    | 変更前 | 変更後 |
    |:-----|:------|
    | `docker.io/dependencytrack/hyades-apiserver` | `docker.io/dependencytrack/apiserver` |
    | `ghcr.io/dependencytrack/hyades-apiserver` | `ghcr.io/dependencytrack/apiserver` |
    | `docker.io/dependencytrack/hyades-frontend` | `docker.io/dependencytrack/frontend` |
    | `ghcr.io/dependencytrack/hyades-frontend` | `ghcr.io/dependencytrack/frontend` |

* **`snapshot` コンテナーイメージタグの廃止**。現在も更新を受けている Dependency-Track のバージョン 4 との競合を防ぐため、`snapshot` タグは更新されなくなりました。`5-snapshot` タグに移行してください。
