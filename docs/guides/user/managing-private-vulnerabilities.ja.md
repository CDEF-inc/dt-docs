# 非公開の脆弱性を管理する

Dependency-Track には、(まだ)公開されていない脆弱性を管理するための、組み込みの非公開の脆弱性リポジトリが含まれています。フィールドの定義と照合の動作については、[非公開の脆弱性リポジトリのリファレンス](../../reference/datasources/private-vulnerability-repository.md)を参照してください。

## 脆弱性を作成する {#creating-a-vulnerability}

サイドバーの **Vulnerabilities** に移動し、**Create Vulnerability** をクリックします。

内部の脆弱性を作成および変更するには、`VULNERABILITY_MANAGEMENT` 権限が必要です。
